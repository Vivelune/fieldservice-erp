## Database Seeding

The project includes a repeatable development demo seed at `prisma/seed.ts`.

The seed is designed to create or update three isolated demo tenants, each with:

- One owner and one technician
- Two customers
- Two jobs
- One invoice associated with a completed job

### Development database only

Use the development Neon branch for migrations and demo data. Never run demo seed operations against the production database.

After confirming the schema and migration, the seed can be executed with:

```bash
pnpm exec prisma db seed --config prisma7.config.ts
```

The seed uses stable demo IDs and upsert operations to avoid creating duplicate tenants and users.

Do not use the demo accounts as real authentication accounts. They are database demonstration records, not verified Better Auth users.
